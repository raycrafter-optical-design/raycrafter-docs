Files and reports

Save your work as a RayCrafter project. Use Zemax files to exchange designs with other programs.

Project files

File → Save and Save As write a project file, ending in .raycrafter; File → Open reads one back. A project keeps the whole design: every lens with its full prescription, all fields, assemblies, locked gaps, the source and image planes and, for an imported design, the original Zemax file. (The Lock focus tick box is not saved.) Because each lens is stored in full, a later change to the catalogue does not change a saved design.

The window title shows the project’s name and marks unsaved changes. RayCrafter asks before New, Open, Import or Quit would throw changes away.

The format may change while RayCrafter is pre-alpha. A file written by a newer format version than your RayCrafter understands is refused.

Importing Zemax files

File → Import ZMX replaces the design with the system in a .zmx file. RayCrafter works with whole lenses, so the import is not exact: a dialog lists whatever was simplified. Read it. See how lenses work compared with Zemax for what changes and what cannot be loaded.

  • The original file is kept. When you save the project, it contains an exact copy of the ZMX file, the import notes and the design as it was first imported. This lets you see where a design came from, and lets a better importer read it again later. (Re-importing from the program is not possible yet.)
  • The title says whether you have changed it, for example “Untitled (imported from lens.zmx, modified)”.
  • Before you share a project, remember the original file is inside it. File → Save Without Original ZMX saves a project without that record; the design then no longer counts as imported.

Exporting to Zemax

File → Export ZMX writes a .zmx file. It does not save your design, because a ZMX file cannot hold all of it:

  • The beam width and vergence come from the selected field only. Every field angle and wavelength is written, but offsets and colours are not.
  • Assemblies, locked gaps and part details are not recorded.

Exported files currently look wrong in Zemax (#9). Do not rely on them yet.

User parts

A user part is a saved assembly. Each is a small .raycrafter-part file in your own data folder, so it is available in every design:

macOS~/Library/Application Support/RayCrafter/parts
Windows%APPDATA%\RayCrafter\parts
Linux~/.local/share/raycrafter/parts

To share a part, copy its file into someone else’s folder. RayCrafter cannot yet rename or delete parts (#62). To delete one, delete its file.

HTML report

Generate report writes a single HTML page about the current design and opens it in your web browser: the first-order numbers, the ray diagram, spot diagram, through-focus curve, MTF, ray fan and field curvature. Click the ? beside a plot for an explanation of what it shows. The report goes in your computer’s temporary folder, so save a copy from the browser if you want to keep it.
