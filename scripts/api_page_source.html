Python API

Everything the window does can be scripted with one object, Bench: a row of lenses on an axis, some beams and an image plane.

The API will change. It is on the main branch (25 November 2026) and may not yet be in the PyPI release. RayCrafter is pre-alpha.

Start

You need Python 3.12 or later. To get the current main branch, with IPython, into a new environment:

pip install ipython "git+https://github.com/raycrafter-optical-design/raycrafter@main"
ipython

All the examples below are one session, run top to bottom. A plot call returns a matplotlib Figure, shown here under the command. In Jupyter, run %matplotlib inline first to see figures like this. In a terminal, save them with .savefig("name.png").

Units and numbering

  • Distances are in mm along the optical axis (z). Light travels towards larger z.
  • Angles are in degrees, vergence in dioptres (positive converging), wavelengths in nm.
  • Lenses are numbered from 0 along the axis, fields from 0 in the order added.

Make a bench

Bench() starts like a new window, with one lens. Bench(empty=True) has none. Both are headless: no window is involved.

from raycrafter import Bench Bench() bench = Bench(empty=True) bench

Find lenses

search_lenses filters the built-in catalogue. Results are sorted by absolute focal length.

found = bench.search_lenses("AC254", min_focal_length_mm=49, max_focal_length_mm=101) for entry in found[:6]: print(f"{entry.part_number:14} f = {entry.focal_length:6.1f} mm {entry.coating}") negative = bench.search_lenses(max_focal_length_mm=-1, min_diameter_mm=24, category="Achromats") [entry.part_number for entry in negative[:5]] entry = bench.catalog["AC254-100-A"] entry.focal_length, entry.clear_diameter_mm, entry.category, entry.family

Place and move lenses

Build a 2:1 beam reducer. Each call returns a LensInfo snapshot.

bench.add_lens("AC254-100-A") bench.add_lens("AC254-050-A", front_z_mm=250) bench.plot("ray_diagram") #figure api-ray-diagram

move_lens behaves like a drag: lenses cannot overlap. Snapshots do not update, so read bench.lenses again after an edit.

bench.move_lens(1, front_z_mm=245).front_z_mm bench.move_lens(1, front_z_mm=90).front_z_mm # push it past the other lens: they swap [(lens.index, lens.part_number, lens.front_z_mm) for lens in bench.lenses]

Flip and delete work by index. An ideal (paraxial) lens takes any focal length.

bench = Bench(empty=True) bench.add_lens("LA1509-A") bench.flip_lens(0).flipped bench.add_paraxial_lens(150, front_z_mm=250).part_number bench.delete_lens(1) len(bench.lenses)

Plössl pairs

Two identical positive lenses that are close together can be snapped into a pair, which then moves as one.

pair = Bench(empty=True) pair.add_lens("AC254-100-A"); pair.add_lens("AC254-100-A"); pair.make_plossl(0) [(lens.front_z_mm, lens.flipped, lens.plossl_group) for lens in pair.lenses] pair.plot("ray_diagram") #figure api-plossl pair.split_plossl(0) [lens.plossl_group for lens in pair.lenses]

Fields (beams)

set_field changes only what you pass. add_field copies the selected field, applies your changes and selects the new one.

bench = Bench(empty=True) bench.add_lens("AC254-100-A"); bench.set_field(0, diameter_mm=8, wavelength_nm=488) bench.add_field(angle_deg=2, colour="#d62728"); bench.add_field(angle_deg=-3, vergence_dioptres=0, offset_mm=1, colour="wavelength"); [(f.index, f.angle_deg, f.offset_mm, f.colour, f.selected) for f in bench.fields] bench.remove_fields([2]) bench.select_field(0) bench.selected_field_index

Focus and summary

autofocus moves the image plane to the smallest RMS spot of the selected field and returns its z.

bench.autofocus() bench.summary() bench.set_image_z(bench.image_z_mm + 0.5) bench.summary().rms_spot_radius_um bench.autofocus();

Plots

plot(kind) draws any of six figures. The ray and spot diagrams show every field. The others show the selected field, or the one given by field_index.

bench.plot("ray_diagram") #figure api-fields-rays bench.plot("spot_diagram") #figure api-spot bench.plot("through_focus") #figure api-through-focus bench.plot("mtf") #figure api-mtf bench.plot("ray_fan", field_index=1) #figure api-ray-fan bench.plot("field_curvature") #figure api-field-curvature

Raw results as NumPy arrays

Each analysis also returns its numbers. Lengths here are in mm unless the name says otherwise.

spot = bench.spots()[0] spot.x.shape, spot.rms_radius * 1000 # rays; RMS radius in µm tf = bench.through_focus() tf.offsets.shape, tf.best_offset, tf.airy_radius mtf = bench.mtf() import numpy as np for f in (10, 25, 50): # cycles/mm t = np.interp(f, mtf.frequency, mtf.tangential) s = np.interp(f, mtf.frequency, mtf.sagittal) print(f"{f:3} cyc/mm T = {t:.3f} S = {s:.3f}") fan = bench.ray_fan(field_index=1) fan.pupil.shape, np.nanmax(np.abs(fan.tangential_error)) curvature = bench.field_curvature() curvature.angles curvature.tangential_shift.round(2)

Plot them however you like:

from matplotlib.figure import Figure fig = Figure(figsize=(7, 3.5)) ax = fig.subplots() for i, name in enumerate(["on axis", "2 deg"]): result = bench.through_focus(field_index=i) ax.plot(result.offsets, result.rms_current * 1000, label=name) ax.set(xlabel="image plane offset (mm)", ylabel="RMS spot radius (µm)") ax.legend() fig #figure api-custom-through-focus

bench.state() returns a copy of the complete design, every surface included, for use with raycrafter.core.analysis. Changing the copy does not change the bench.

Sweeps

Scripting pays off when you compare many configurations. Which way round should a plano-convex lens go?

for part in ("LA1509-A", "AC254-100-A"): test = Bench(empty=True) test.add_lens(part) for _ in range(2): test.autofocus() s = test.summary() print(f"{part:12} flipped={test.lenses[0].flipped!s:5} " f"RMS = {s.rms_spot_radius_um[0]:7.2f} µm Airy = {s.airy_radius_um[0]:.2f} µm") test.flip_lens(0)

How does spot size grow with beam diameter?

diameters = np.arange(2, 21, 2) curves = {} for part in ("LA1509-A", "AC254-100-A"): test = Bench(empty=True) test.add_lens(part) rms = [] for d in diameters: test.set_field(0, diameter_mm=d) test.autofocus() rms.append(test.summary().rms_spot_radius_um[0]) curves[part] = rms fig = Figure(figsize=(7, 3.5)) ax = fig.subplots() for label, rms in curves.items(): ax.semilogy(diameters, rms, "o-", label=label) ax.set(xlabel="beam diameter (mm)", ylabel="RMS spot radius at best focus (µm)") ax.legend() fig #figure api-sweep

Drive the open window

Start RayCrafter (raycrafter in another terminal), then use Bench.connect(). The methods are the same, but each edit happens in the window and it redraws. The script also sees changes you make by hand. The link only listens on your own computer. It is off if RayCrafter was started with --no-agent-link.

live = Bench.connect() live live.is_connected live.new_design(discard_unsaved=True) live.add_lens("AC254-100-A"); live.add_lens("AC254-050-A", front_z_mm=180); live.add_field(angle_deg=1.5, colour="#d62728"); live.select_field(0) live.autofocus() #screenshot api-window

Move a lens from the script and the window follows:

live.move_lens(1, front_z_mm=140); live.autofocus() #screenshot api-window-moved

Which index is which?

The Bench list in the window shows every lens and field with the index the API uses. Selecting a row highlights it in the side view. Here lens 1 is selected.

#bench-viewer [(lens.index, lens.part_number) for lens in live.lenses] #screenshot api-viewer

Files and reports

Save and load Zemax .zmx files, and write the HTML report. load_zmx returns a list of notes on anything RayCrafter simplified. See how lenses differ from Zemax.

bench.has_unsaved_changes bench.save_zmx("reducer.zmx") bench.has_unsaved_changes reloaded = Bench.from_zmx("reducer.zmx") [lens.part_number for lens in reloaded.lenses] reloaded.load_zmx("reducer.zmx", discard_unsaved=True) bench.write_report("design.html") # add open_in_browser=True to view it

Errors

A request that makes no sense raises ValueError with an explanation. Bench.connect() raises ConnectionError if no window answers.

bench.add_lens("AC999-000-Z") # raises bench.flip_lens(7) # raises bench.add_lens("LA1509-A"); bench.new_design() # raises
