# RayCrafter docs

[Documentation site](https://raycrafter-optical-design.github.io/raycrafter-docs/) for [RayCrafter](https://github.com/raycrafter-optical-design/raycrafter),
served with GitHub Pages. Plain HTML and one shared `style.css`: no build step.

- `index.html` and the other `.html` files: the pages
- `python-api.html` is generated, so edit `scripts/api_page_source.html` and run
  `scripts/make_api_page.py` (instructions in its docstring)
- `img/`: screenshots, regenerated by `scripts/make_screenshots.py` (instructions in its docstring)

To preview locally: `python3 -m http.server` in this folder.
